# Lab 5: Interrupts (quadrature encoder)

Build in SEGGER Embedded Studio like Lab 6: new STM32L432KC project, add every `.c` in `src/` and `lib/`,
and add `src/` and `lib/` to the include paths. Output prints in SES's debug terminal.

Wiring: encoder A -> PA6, encoder B -> PA8, encoder VCC -> 5 V, GND -> GND. Motor on a separate 12 V supply.
